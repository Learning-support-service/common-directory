---
description: 스마트 커밋 스킬을 사용하여 변경 사항을 커밋하고 푸시합니다.
---

1. **스킬 참조**: `.agent/skills/smart_commit/SKILL.md` 파일을 읽고 숙지합니다.
2. **변경 사항 확인**: `git diff` 또는 `git status`를 사용하여 변경된 내용을 분석합니다.
3. **커밋 메시지 생성**: "Smart Commit" 스킬의 규칙(한국어, Conventional Commits)에 따라 커밋 메시지를 생성합니다.
4. **커밋 실행**: 생성된 메시지로 `git add .` 및 `git commit -m "..."`을 실행합니다.
5. **푸시 판단**: 사용자가 명령어 뒤에 `-p` 플래그를 붙였는지 확인합니다.
    - `-p`가 **있는 경우에만** `git push`를 실행합니다.
    - `-p`가 없다면 커밋까지만 하고 종료합니다.
